# INSIGHT Risk Prototype

Static prototype gallery and evaluation pages for testing INSIGHT Risk result presentation formats.

## Files

- `index.html`: Internal setup page
- `evaluation.html`: Customer-facing evaluation page
- `styles.css`: Shared styling
- `script.js`: Shared prototype rendering and interaction logic

## Local Preview

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Deployment

This project is a static site and can be deployed directly to Vercel or other static hosting providers without a build step.
